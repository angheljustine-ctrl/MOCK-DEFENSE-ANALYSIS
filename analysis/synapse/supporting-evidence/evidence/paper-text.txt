INTRODUCTION 
This project is a web-based Clothing Inventory Management and Point of Sale (POS) System that we 
created for our subject Web System Technologies with JavaScript. We developed it for SynapseTen 
Inc., a clothing line business that started in 2022 in Valenzue la, Metro Manila. SynapseTen focuses 
on making high-quality, durable, and stylish clothing such as shirts, caps, pants, shorts, joggers, and 
other apparel. They also accept custom printing and bulk orders for schools, businesses, and events. 
The company wa s established after the pandemic because the founders noticed that people kept 
buying the same brands, and they wanted to offer something fresher and more reliable. 
Many small clothing stores still depend on notebooks or simple spreadsheets to track their products. 
This becomes a big problem because clothes come in different sizes and colors, so it is easy to lose 
track of what is still available. Sometimes the record ed stock does not match what is actually on the 
shelves, which can lead to overselling or running out of popular items. Updating records after every 
sale also takes time and can cause errors, especially when the store is busy. Doing calculations and 
writing receipts by hand also slows down the checkout process for customers. 
Because of these challenges, we decided to create a system that can help clothing store staff manage 
products and process sales more easily and accurately. Our system allows users to add, edit, delete, 
and search for clothing items. It also has a Point-of-Sale feature where staff can process transactions, 
apply discounts, accept payments, and generate receipts. The inventory is automatically updated 
every time a product is sold, so there is less chance of mistakes. We used JavaScript to make the 
system inte ractive, especially for form validation, real -time stock updates, calculating totals, and 
saving data using the browser’s Local Storage.

more efficiently. Users can add, edit, delete, and search for clothing items, including different sizes

receipts ma nually also slows down the checkout process. Many small businesses cannot afford 
expensive commercial POS systems or complicated database setups, so they need a simpler solution.

PROJECT GOAL AND OBJECTIVES 
3.1 The main goal of this project is to develop a simple, efficient, and user -friendly web -based 
Inventory Management and Point of Sale System for SynapseTen Inc. The system should help staff 
manage clothing products, monitor inventory in real time, process sa les transactions, and keep 
organized records using HTML, CSS, JavaScript, and the browser’s Local Storage. 
 
3.2 Specific Objectives  
• To design and develop a web-based Inventory Management and POS System with a clean 
and organized interface for a clothing business.  
• To allow users to easily add, edit, delete, and search for clothing products.  
• To automatically update stock quantities whenever a product is sold or adjusted.  
• To record sales transactions and keep a history of completed sales.  
• To store product and sales data using the browser’s Local Storage so that no external 
database is needed.  
• To organize inventory and sales records in order to reduce errors from manual recording.  
• To generate sales and inventory reports that can help in monitoring business performance 
and deciding when to restock.  
• To provide a practical system that can be used by clothing businesses and also serve as a  
learning tool for students.

4. PROJECT SCOPE 
This system covers the important functions needed to manage inventory and sales in a clothing store. 
It is designed for the staff of SynapseTen Inc. and other similar small to medium clothing businesses. 
The system handles product information such as name,  code, category, brand, size, color, price, and 
stock quantity, as well as sales records and user accounts. 
The main modules include Login, Dashboard, Product Management, Point of Sale, Stock In and 
Adjustment, Reports, and Settings. We used JavaScript for form validation, real -time updates, sales 
calculations, and saving data in Local Storage. 
 
4.1 Included Features: 
• Secure login with different user roles (Admin and Staff)  
• Dashboard that shows total products, critical stocks, sales summary, and top-selling items  
• Product management (add, view, edit, delete, and search products with size and color options)  
• Point of Sale for processing transactions, applying discounts, handling payments, and 
generating receipts  
• Stock-in, recording of damaged products, and stock adjustment  
• Sales reports, damage reports, and out-of-stock reports  
• Settings for managing user accounts, product discounts, and backup/restore  
• Automatic inventory update after every sale  
• Form validation and dynamic content using JavaScript

5. PROJECT LIMITATIONS 
 
• The system only works on web browsers and does not have a mobile application version.  
• All data is saved in the browser’s Local Storage, so it is not connected to an external database.  
• The system is best suited for small to medium clothing stores and may not be enough for very 
large businesses.  
• Some features, like full system settings, are only available to Admin users.  
• Core functions can work without internet, but accessing the system from different devices or 
locations may have limitations because of Local Storage.  
• The system does not support advanced features found in commercial POS software.

POS (Point of Sale) System records the selected products, calculates the total amount, and allows

the available stock, process payments, update the order status, and assist customers during checkout. 
The POS helps the staff reduce manual recording and keeps sales and inventory information 
organized.

11.  CONCLUSION 
Overall, we were able to create a working web -based Inventory and POS System for SynapseTen 
Clothing. The system helps the store manage their products better, especially since clothes come in 
different sizes and colors, which makes tracking stock harder when done manually. 
With this system, staff can add and update products, process sales quickly, see low stock alerts, and 
keep a record of transactions. We also added different access levels so Admin and Staff have different 
permissions. Everything runs using HTML, CSS, and JavaScript, and data is saved in Local Storage 
so there’s no need for a complicated database. 
We think we achieved most of our goals. The system is simple to use, updates stock automatically 
after every sale, and has basic reports that can help the store monitor their performance. Working on 
this project helped us understand how JavaScript can make a website more interactive and useful for 
real businesses. 
Of course, the system still has some limitations. Since it only uses Local Storage, the data stays on 
one browser, and it’s not yet ready for bigger stores. In the future, it would be better if we could 
connect it to a real database, add barcode scanning, or even make a mobile version. 
Still, for a student project, we are satisfied with what we finished. It showed us how web technologies 
can solve everyday problems in a clothing business like SynapseTen.
