P23: INTRODUCTION
P24: The EduCore Technologies (SIMS) is a web-based information management system developed as part of the requirements for the subject Web System Technologies with JavaScript. It is a system that will help organize and manage important academic information like student record, teacher record, subjects, classes, enrollment, attendance, grades, announcements and reports.
P25: The system is designed to address the need of a centralized and organized platform from where school administrators, teachers and students can access information according to their respective roles. EduCore provides a web-based structured interface to manage and view academic information in case of manual or separate file records.
P26: The system demonstrates how JavaScript can be used to build an interactive web application. In JavaScript, functions like form validation, CRUD, login authentication, manipulation of data, dynamic content creation, search, notifications, modal dialog, user interaction etc. are taken care of. EduCore is designed for three main types of users: Administrators, Teachers and Students. Each user’s role determines what permissions they have and what system features they can access.
P28: PROJECT OVERVIEW
P29: System Name
P30: EduCore Technologies (SIMS)
P31: Description of System
P32:     EduCore SIMS is a role-based web system designed to manage academic and administrative information in a school environment.
P33:      The system consists of an Admin interface for managing students, teachers, subjects, classes, enrollment, announcements, orders, reports, system settings, and the school store. Teachers can view the subjects and classes they are assigned to, manage students, take attendance and record grades, view announcements, and manage their account settings. Students can view their academic information and other features available to their account.
P34:      The system uses HTML, CSS, and JavaScript as its primary web technologies. Data is stored using the browser's Local Storage, allowing the system to operate without requiring a traditional server-side database.
P35:     The system also uses role-based access control to ensure that users are directed to the appropriate pages and functions according to their account type.
P37: Statement of problem
P38: Manual or distributed file storage can make it difficult to manage student and academic records. Searching for records, updating information, managing classes, recording grades, and communicating announcements can be time-consuming and labor intensive.
P39: There is also a need to provide easier access to academic information for teachers and students while restricting administrative functions to authorized users.
P40: Hence the project addresses the need for an organized web-based system to manage the academic records with different functionalities based on user roles.
P41: Proposed Solution
P42: The proposed solution is the development of EduCore SIMS, a web-based student information management system that centralizes important academic records into one platform.
P43: The system provides CRUD operations for records, role-based login, searchable tables, class and subject management, attendance and grade management, announcements, reports, and account settings.
P44: JavaScript is used to dynamically process information, validate forms, update records, display notifications, control modals, manage authentication, and interact with Local Storage.

P168: PROJECT LIMITATIONS
P169: The following limitations apply to the current version of EduCore SIMS:
P170: The system is designed primarily for web browsers.
P171: The project does not include a dedicated mobile application.
P172: The system currently uses browser Local Storage instead of a server-based database.
P173: Data stored in Local Storage is limited to the browser and device where the system is being used.
P174: Clearing browser storage may remove stored system data.
P175: The system does not currently provide a cloud-based synchronization system.
P176: The system does not include advanced server-side security.
P177: The system does not include an external email notification service.
P178: The system does not include real-time communication between users.
P179: Administrative functions are restricted to authorized administrator accounts.
P180: Teacher functions are restricted to authorized teacher accounts.
P181: Student functions are restricted to authorized student accounts.
P182: The system is intended primarily as an academic project and prototype rather than a production-ready school information system.

P281: SYSTEM DESIGN
P282: System Flowchart
P284: System Flowchart Explanation
P285: The system begins with the opening or loading page. The user is directed to the login page where they enter their credentials.
P286: The system validates the entered username and password. If the credentials are incorrect, the user remains on the login page and receives an error message.

P288: The user can then access the modules available for their role. Data entered into the system is processed using JavaScript and stored in Local Storage.
P289: When the user performs an action such as adding, editing, searching, or deleting information, JavaScript processes the action and dynamically updates the displayed information.
P290: The user can continue using the system until they choose to log out.

P421: CONCLUSION
P422: The EduCore Technologies (SIMS) was successfully developed as a web-based academic information management system using HTML, CSS, and JavaScript.
P423: The project provides separate interfaces for administrators, teachers, and students. It includes important functions such as user authentication, student management, teacher management, subject management, class management, enrollment, attendance, grades, announcements, reports, search, CRUD operations, and account settings.
P424: The project's objectives were achieved by implementing interactive JavaScript functionality throughout the system. JavaScript played an important role in validating forms, processing user actions, managing authentication, manipulating records, filtering information, controlling modals, displaying notifications, and storing data through Local Storage.
P425: The development of EduCore SIMS also provided practical experience in designing user interfaces, organizing web pages, implementing role-based access, handling data, and creating interactive web applications.
P426: Although the current system has limitations such as relying on browser Local Storage and not having a server-side database, it provides a functional foundation for a Student Information Management System.
